# SJF: The Last Process

An interactive RPG-inspired learning experience about Shortest Job First scheduling and AI, created for the Computer Architecture seminar at PIT.


## Run locally

Requirements: Node.js 20+ and npm.\n
```bash
npm install
npm run dev
```
Open http://localhost:3000.

## Current prototype (v0.1)
- cinematic landing page
- expandable character profiles for six team members
- chapter selector / mission preview
- responsive layout
- first concept art in `public/assets/heroes-concept.png`\n
## Planned next
- chapter/mission flow
- process scheduling simulator (FCFS, SJF, SRTF, Round Robin)
- interactive Gantt chart
- audience voting via QR / shared session backend
- presenter mode
- accessibility and offline presentation fallback

```bash
git init

git commit -m "feat: create SJF The Last Process prototype"
git branch -M main
git remote add origin https://github.com/YOUR-USERNAME/sjf-the-last-process.git
git push -u origin main
```
Replace `YOUR-USERNAME` with your GitHub username.
